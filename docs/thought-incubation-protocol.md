# 思想孵化协议

每轮首先识别用户动作，再根据当前节点状态选择一个认知功能。默认只产生一次简短介入，并把话语权交还用户。AI 产生的解释、候选重述和延展都以 ai_* 认识论状态保存，不能自动写成用户观点。

确认操作：

- 准确表达了我：候选节点 → accepted_claim / user_accepted
- 部分准确：候选节点 → partially_accepted，说明会成为新的用户事件
- 误解了我：候选节点 → user_rejected，说明会成为新的用户事件
- 先作为候选：保持 ai_proposal
- 拒绝这个表达：候选节点 → user_rejected

多视角入口最多调用三个功能，且前台保持候选状态。当前实现的 Mock Provider 每轮最多一个介入，避免无限循环。
